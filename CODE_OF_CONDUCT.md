# Code de conduite

## Notre engagement

Nous souhaitons offrir un espace accueillant, respectueux et sans harcèlement à toutes les personnes qui utilisent ou améliorent ce projet.

## Comportements attendus

- communiquer avec respect et précision ;
- accueillir les retours constructifs ;
- se concentrer sur le problème technique ;
- protéger les informations privées et les signalements de sécurité.

## Comportements inacceptables

Le harcèlement, les attaques personnelles, les propos discriminatoires, la publication d’informations privées et toute conduite délibérément perturbatrice ne sont pas acceptés.

## Application

Les responsables du projet peuvent modifier ou supprimer les contributions qui ne respectent pas ces règles. Les incidents peuvent être signalés à SAS Jessy System depuis [jessysystem.com](https://jessysystem.com).
