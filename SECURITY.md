# Politique de sécurité

## Versions prises en charge

La dernière version publiée de WP Simple Template Switch reçoit les correctifs de sécurité.

## Signaler une vulnérabilité

Ne publiez pas de vulnérabilité exploitable dans une issue GitHub.

Contactez SAS Jessy System depuis [jessysystem.com](https://jessysystem.com) avec :

- la version concernée ;
- les étapes minimales de reproduction ;
- l’impact estimé ;
- une proposition de correctif, si disponible.

Un accusé de réception sera envoyé dès que possible. Merci de laisser un délai raisonnable pour analyser et corriger le problème avant toute divulgation publique.
