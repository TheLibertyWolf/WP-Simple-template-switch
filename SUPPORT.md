# Support

Pour une question d’utilisation ou un bug reproductible, ouvrez une issue GitHub avec :

- les versions de WordPress, PHP et du plugin ;
- le type d’installation, simple ou Multisite ;
- les thèmes parent et enfant concernés ;
- le rôle du compte affecté ;
- les étapes de reproduction et le résultat attendu.

N’incluez jamais de mot de passe, cookie de session, jeton ou donnée personnelle.

Les vulnérabilités doivent suivre la procédure privée décrite dans [SECURITY.md](SECURITY.md).
